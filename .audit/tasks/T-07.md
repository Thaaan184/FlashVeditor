# Task T-07: Uji Sanitasi Env Var pada Launcher

## Tujuan
Memastikan launcher (`plugins/ai-editor/lib/ai_editor/launcher.py`) tidak menghilangkan variabel lingkungan gateway (`ANTHROPIC_BASE_URL`, `ANTHROPIC_API_KEY`, `ANTHROPIC_MODEL`, `GEMINI_BASE_URL`, dll.) saat membuka terminal session baru untuk Claude Code, baik pada platform Linux, macOS (Darwin), maupun Windows.

## Kriteria Lulus
1. `launcher.py` meneruskan seluruh set `env_keys` gateway ke perintah `env ...` di terminal baru.
2. Uji simulasi launcher Darwin dan Linux memverifikasi `ANTHROPIC_BASE_URL` dan model alias tetap ada di baris perintah.
3. Subprocess anak mewarisi `ANTHROPIC_BASE_URL` tanpa ter-drop.
4. `launcher.py demo` dan `tests/check_plugins.py` lulus `ok`.
5. Nol rahasia/token tercatat di log bukti.
