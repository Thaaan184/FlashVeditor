# Task T-15: Refaktor UI De-Claude, Pemilihan Gateway AI, dan Daemon Auto-Worker

## Tujuan
1. Menghapus ketergantungan terminologi spesifik Claude Code dari antarmuka Web UI (`home.html`, `review.html`) agar pengguna tidak ambigu dengan instruksi manual terminal.
2. Menyediakan panel pemilihan dan konfigurasi AI Gateway pada tampilan awal (Onboarding) dan Pengaturan (Settings), mencakup 9Router Gateway (`ag/gemini-3.8-flash-high`), Claude Direct, dan Custom LLM Gateway.
3. Menyediakan background daemon `worker.py` yang otomatis mengeksekusi antrean pipeline editing (teardown, download, transkripsi Whisper, pengukuran visual, dan analisis Gemini via 9Router) tanpa memerlukan intervensi manual terminal.

## Komponen yang Diubah
- `plugins/ai-editor/lib/ai_editor/home.html`: Refaktor status teks dari "Waiting for Claude" menjadi pemrosesan otomatis via 9Router, penambahan panel AI Gateway Connection.
- `plugins/ai-editor/lib/ai_editor/review.html`: Pembersihan istilah Claude menjadi AI Editor.
- `plugins/ai-editor/lib/ai_editor/home.py`: Penambahan route `GET /gateway` dan `POST /gateway`, penambahan metadata gateway aktif pada endpoint `GET /state`.
- `plugins/ai-editor/lib/ai_editor/worker.py`: Daemon auto-worker pemroses antrean job `home.py wait`.
- `docker-entrypoint.sh`: Otomatisasi inisiasi `worker.py` di latar belakang saat server berjalan.
