# Task T-04: Template .env dan .env.example

## Tujuan
Menyediakan template konfigurasi `.env.example` yang mencakup:
- Opsi A (Direct Google AI Studio)
- Opsi B (9Router lokal gateway dengan model visual kustom)
- Opsi C (ElevenLabs)

Memastikan:
- Lokasi file cocok dengan loader (`~/.config/creator-teardown/.env` dan `$AI_EDITOR_HOME/.env`).
- Loader `keys.py` mendukung `GEMINI_BASE_URL` dan `GEMINI_AUTH_MODE`.
- `.env` dan `*.env` diabaikan oleh git via `.gitignore`.
- Tidak ada nilai rahasia/token riil dalam diff atau repository.

## Kriteria Lulus
1. `.env.example` ada di root repository dengan opsi lengkap dan instruksi jelas.
2. `.gitignore` mengabaikan `.env` dan `*.env` (kecuali `.env.example`).
3. `keys.py` dan `check_plugins.py` tetap valid dan lulus uji `keys ok`.
4. Nol token atau rahasia yang ter-commit.
