# Task T-10: Panggilan Visual Creator-Teardown ke Gateway Gemini (ag/gemini-3.8-flash-high)

## Tujuan
Memastikan fungsi analisis visual creator-teardown (`gemini.py look`) sukses memproses klip video nyata dengan mengirimkan panggilan visual frame sampling ke gateway 9Router lokal (`http://127.0.0.1:20128`) menggunakan model `ag/gemini-3.8-flash-high`.

## Kriteria Lulus
1. `gemini.py look` memproses berkas video dan mengirimkan frame array JPEG base64 ke endpoint gateway `/v1beta/models/ag/gemini-3.8-flash-high:generateContent`.
2. Menghasilkan berkas analisis visual `.look-ai.json` dengan identitas model `ag/gemini-3.8-flash-high`.
3. Menghasilkan token usage > 0 (bukti inferensi multimodal nyata).
4. Menghasilkan pembaruan `style.json` yang memuat preferensi font (Google Fonts), gaya teks caption, dan gaya motion.
5. Log bukti tersimpan di `.audit/evidence/T-10/teardown-gateway-evidence.txt`.
