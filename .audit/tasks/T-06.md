# Task T-06: Verifikasi Model Mapping di Gateway (Haiku, Sonnet, Opus)

## Tujuan
Memastikan seluruh alias model Claude Code terpetakan dengan benar ke model yang aktif pada gateway 9Router lokal (`http://127.0.0.1:20128`), mencegah error 404 pada sub-task background atau side-calls:
- `ANTHROPIC_DEFAULT_HAIKU_MODEL`: `ag/gemini-3.8-flash-high`
- `ANTHROPIC_DEFAULT_SONNET_MODEL`: `ag/claude-sonnet-4-6`
- `ANTHROPIC_DEFAULT_OPUS_MODEL`: `ag/claude-opus-4-6-thinking`
- `ANTHROPIC_MODEL`: `ag/claude-sonnet-4-6`

## Kriteria Lulus
1. Panggilan streaming `/v1/messages` untuk setiap model alias mengembalikan HTTP 200 dengan payload SSE valid.
2. Uji negatif membuktikan nama model asli Claude yang belum dipetakan (misal `claude-3-5-haiku-20241022`) ditolak HTTP 404 oleh gateway, membuktikan mutlaknya konfigurasi pemetaan alias di `settings.local.json`.
3. Nol rahasia/token tercatat di file bukti log.
