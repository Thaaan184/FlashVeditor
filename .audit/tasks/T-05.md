# Task T-05: Template settings.local.json dan settings.local.json.example

## Tujuan
Menyediakan konfigurasi agen Claude Code agar mengarah ke gateway lokal 9Router (`http://127.0.0.1:20128`) menggunakan format resmi Claude Code settings:
- File `.claude/settings.local.json.example` tersedia di repository tanpa rahasia.
- File `.claude/settings.local.json` aktif secara lokal dan terabaikan oleh `.gitignore`.
- Blok `env` mendefinisikan `ANTHROPIC_BASE_URL`, `ANTHROPIC_API_KEY`, dan pemetaan model alias (`ANTHROPIC_MODEL`, `ANTHROPIC_DEFAULT_HAIKU_MODEL`, `ANTHROPIC_DEFAULT_SONNET_MODEL`, `ANTHROPIC_DEFAULT_OPUS_MODEL`).

## Kriteria Lulus
1. `.claude/settings.local.json.example` ada di repo tanpa API key asli.
2. `.claude/settings.local.json` ada di lokal dan tidak masuk git status (`.gitignore` efektif).
3. JSON schema valid (`claude-code-settings.json`).
4. `check_plugins.py` tetap valid.
